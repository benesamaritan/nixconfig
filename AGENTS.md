# AGENTS.md — nixconfig

Personal Nix setup for a regular (non-NixOS) Linux machine. Determinate Nix package manager; standalone Home Manager flake for the user environment. No NixOS host config on `main`.

## Commands (run from repo root)

```sh
home-manager switch --flake .#benesamaritan   # apply user config (also: nh home switch)
home-manager build --flake .#benesamaritan    # build without activating
nix flake lock                                # after adding/changing flake inputs
```

## Layout

- `flake.nix` — inputs + single output `homeConfigurations."benesamaritan"`.
- `users/benesamaritan/home.nix` — entry point; imports `age.nix`, `programs.nix`, `genericLinux.nix`, `services`, `profiles/{personal,dev,work}`, `profiles/dotfiles`, plus agenix/nix-index-database/nix-flatpak HM modules.
- `profiles/dev/` — `config.nix`, `tools.nix`, `editors.nix`, `languages.nix`, `formatting.nix`, `platforms.nix`, `mcp.nix`, `skills.nix`.
- `profiles/personal/` — fonts, browsers (zen, helium), productivity, catppuccin theming; `entertainment.nix.disabled` is intentionally excluded.
- `profiles/work/` — import commented out in `home.nix`.
- `services/` — user services (ssh-agent, kdeconnect; gpg-agent present but disabled).
- Each of `profiles/{dev,personal,work}` and `services/` has a `default.nix` that auto-imports every regular `*.nix` sibling. Flakes only see tracked sources — `git add -N <file>` before dropping a new module, or it is silently skipped. Disable a module by renaming to `*.nix.disabled` (not commenting out). Never place helper `.nix` files there.

## Determinate Nix rules (do not violate)

- `/etc/nix/nix.conf` is generated by Determinate — never edit it. System-wide tweaks go in `/etc/nix/nix.custom.conf` (needs sudo).
- Never put secrets in `nix.settings` (world-readable store file). Use `nix.extraOptions = "!include …"` pointing at an agenix-decrypted file, with `nix.checkConfig = false`.
- Flake-level `nixConfig` substituters only take effect once accepted into `~/.local/share/nix/trusted-settings.json`.
- Git commits/tags are GPG-signed (`signing.key = "3C703A64157458C1"`, `signByDefault`). Commit email must match a GitHub account email or the badge shows Unverified. Never commit unless asked; if asked in an environment without the key, use `git -c commit.gpgSign=false` inline. GitHub SSH uses `~/.ssh/github` (`IdentityFile` + `IdentitiesOnly`). gpg-agent handles GPG passphrases; plain `ssh-agent` handles SSH keys — keep separate (`gpg-agent.enableSshSupport = false`).

## Conventions

- Home Manager modules receive flake inputs via `extraSpecialArgs` (`{ ..., inputs, ... }:`).
- `programs.nix-index` + `nix-index-database.comma` provide `command-not-found`. Never add `nix-index` to `home.packages` (conflicts with the DB wrapper).
- MCP servers declared once in `profiles/dev/mcp.nix`, fanned out via `programs.mcp.servers`. OpenCode has `enableMcpIntegration = true` in `profiles/dev/platforms.nix`, so HM generates `~/.config/opencode/opencode.json` from `programs.mcp.servers` — do not hand-edit `opencode.json`.
- Servers needing tokens use `env.<VAR>.file` pointing at an agenix-decrypted file — never literal secrets.
- `pkgs.codegraph` segfaults on glibc 2.44 (bundled Node incompatible). `codegraph` is declared as a custom derivation in `mcp.nix` fetching the upstream v1.6.2 JS bundle and running it with `pkgs.nodejs_22` (Node 22 LTS — Bun reports v26.3.0 which codegraph otherwise rejects). `jscpd` is enabled with `NODE_OPTIONS="--max-old-space-size=1024"` and scoped to `src` to avoid OOM — do not remove those constraints.
- Flatpaks via `nix-flatpak` flake (`services.flatpak` in `services/flatpak.nix`, flathub remote, weekly auto-updates). Keep `uninstallUnmanaged = false`.
- GPU on non-NixOS via `targets.genericLinux.gpu.enable` (needs one-time `sudo /nix/store/.../non-nixos-gpu-setup`; activation re-announces until done). Never mix with nixGL. Flatpak apps need neither.
- Helix fully managed in nix via `programs.helix` (`settings` + `languages`) — never re-add a helix out-of-store link (fights HM-owned `~/.config/helix`).
- Dotfiles (wezterm, kanata, starship, fastfetch, nvim, …) live in a separate `dotfiles` repo and are linked with `mkOutOfStoreSymlink` in `profiles/dotfiles/*.nix`.
- Catppuccin (mocha, pink) theming via the `catppuccin` flake's home module.
- Unused flake input `affinity-nix` is kept intentionally (with its substituter).
- `legacy-nixos` branch preserves the old NixOS config (`hosts/`, `modules/`). Never reintroduce NixOS modules onto `main` without asking.
